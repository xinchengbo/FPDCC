# FPDCC

This repository provides the core code for **FPDCC (Flow Persistence Driven Congestion Control)**.
FPDCC is implemented based on the [ENCC](https://github.com/wangxinshuo0421/ENCC) simulation code library.

## Source Code
The FPDCC implementation is located in the [`src/`](./src/) directory. It contains the topology (topology_400.txt), configuration (config.txt), switch core files (rdma-hw.cc/h), and sender core files (switch-node.cc/h).
